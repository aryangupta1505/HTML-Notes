Introduction to HTML

Video Link

HTML stands for HyperText Markup Language. It is the standard language used to create web pages by structuring content using elements called tags.

1. The Core Structure

Every valid HTML5 document requires these fundamental building blocks:

  • <!DOCTYPE html> - Tells the browser that this file is an HTML5 document.
  • <html> - The root container that wraps all the code on the page.
  • <head> - Contains invisible metadata about the page, links to CSS stylesheets, and character settings.
  • <title> - Nested inside the head; sets the official title seen on the browser's tab.
  • <body> - The main container for all visible content (paragraphs, images, tables, headings) displayed to users.
